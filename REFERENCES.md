# Reference Library

The project's reference PDFs are stored outside this repository at:

`D:\MTech\MastersCode\FinalSem\References\`

The library is organized into these topic folders:

- `Latest/` contains the current general reference collection. The Riedl paper, *Emergent Coordination in Multi-Agent Language Models*, is `Latest/12455_Emergent_Coordination_in.pdf`.
- `PID/` contains partial information decomposition references.
- `Willam Beer/` contains Williams and Beer's original PID paper, `Willam Beer/1004.2515v1.pdf`. The folder name is spelled `Willam Beer` on disk.
- `Synergy/` contains synergy and information-dynamics references.
- `O-Information/` contains O-information references, including `O-Information/2601.08030v1.pdf`.

Use the PDFs in this external library when checking source definitions or page references for the report. The paths above refer to the current Windows machine and may need adjustment on another machine.
